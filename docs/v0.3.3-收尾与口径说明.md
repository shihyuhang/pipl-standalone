# v0.3.3 收尾与口径说明

## 版本定位

v0.3.3 是 v0.3 主链的体验与口径收尾版本。当前版本号以 `package.json` 和 README 为准，历史评估报告保留其检测当时的版本标识，不回溯改写。

## 首页口径

- 适用路径：根据当前单位事实实时计算；标题、颜色、图标、状态徽章和辅助提示统一使用同一次计算结果。
- 单位建档：单位首次建档已经完成。
- 业务记录：至少存在一项业务记录。
- 材料发布：至少存在一份当前有效的已发布材料；草稿不计入完成。
- 全面检查：至少一份官方合规自查已经由负责人确认归档。
- 持续留痕：首次正式自查归档后，又形成材料发布、材料复核结论、业务初步检查、后续自查归档或影响评估归档记录。

进度仅表示系统内已经留存的工作证据，不表示取得合规认证，也不替代专业法律判断。

## 材料复核提醒

首页仅统计状态为“需要确认”或“逾期未处理”的材料。正在修订但尚未发布的材料继续在材料中心办理，不重复计入首页变化提醒。

## 数据接口

Dashboard 不再返回完整自查实例列表，只返回首页和归档概览所需的计数，以及首次正式自查后的有效后续记录数量，避免重复传输未使用的自查答卷数据。
