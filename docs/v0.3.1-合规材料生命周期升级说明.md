# v0.3.1 合规材料生命周期升级说明

## 目标

将“合规材料”从草稿生成和简单版本列表升级为企业自己的材料生命周期中心，能够回答当前有效版本、修改原因、业务一致性、审批发布和历史证据五个问题。

## 本次实现

- 材料和版本状态分离：材料可处于尚未发布、内容一致、需要确认、草稿待发布或逾期未处理；
- 小型处理者采用“生成/编辑草稿—负责人直接发布”的简化流程；
- 草稿可继续编辑；已发布版本不可修改，恢复历史内容需要创建新草稿；
- 发布前由负责人直接核对，系统不再强制设置经办、复核和批准岗位；
- 发布记录保存内容哈希、发布人、发布渠道和发布证据；
- 版本保存来源版本、企业档案和关联业务事实快照；
- 企业名称、联系人、敏感信息、未成年人、境外情况以及关联业务事实变化时，自动生成材料复核提醒；
- 提醒明确变化字段和建议核对章节，可创建草稿、说明无需修改或暂缓处理；
- 材料中心提供当前概况、版本历史、版本对比、业务依据和发布记录；
- 草稿不再作为已经建立正式告知材料的证据；
- 修复版本可跨材料发布的归属校验问题；
- 材料类型切换时同步更新默认适用范围；
- 对外材料补充联系人和职务、敏感信息、未成年人、第三方接收方及境外处理等章节。
- 材料新增独立的“面向人群”范围，先分人群、再选择材料类型和业务；
- 对外声明按消费者、业务联系人、员工、候选人和访客分别管理，员工与候选人不得混入同一份告知；
- 同一人群下默认允许一份材料关联多项业务，仅在告知时点、渠道或责任主体确实不同时另建材料；
- 内部制度、操作指引和台账可跨人群覆盖多项业务；
- 材料中心展示各对外人群的业务数量、材料数量和未被有效版本覆盖的业务；
- 旧版员工告知如包含招聘场景，将保留历史版本和事实快照，移出当前关联并提示建立候选人告知。
- 材料入口不再以隐私声明为中心，新增“法规材料全景”，统一展示对外材料、内部制度、处理协议、业务台账、办理记录、审计自查和影响评估；
- 材料目录明确区分“基础材料、条件触发、留痕材料”，避免小型处理者被要求一次性建立不适用的材料；
- 新增委托处理协议、共同处理权责约定、个人权利请求记录、单独同意及撤回记录、个人信息安全事件处置记录；
- 新增未成年人专门处理规则、敏感个人信息单独同意、个人信息出境告知与单独同意、安全事件个人通知；
- 每种材料显示主要法规依据和适用情形，并随材料版本保存；
- 合规审计自查表和个人信息保护影响评估继续使用各自的专门模块，以保留逐项判断、签署和归档能力，不重复生成普通文档模板。
- 新增系统内“AI 设置”，可以为材料草稿选择 DeepSeek、通义千问、Kimi 或其他 OpenAI 兼容服务，配置接口地址、模型和API密钥并测试连接；
- API密钥使用本机凭据密钥加密保存，浏览器端只能读取“是否已经配置”，不能读取密钥明文；
- 材料生成支持“AI生成完整草稿”和“生成基础模板”两种方式；AI仅使用所选材料需要的企业档案、已确认业务事实和基础模板；
- AI生成前必须由负责人查看服务端生成的实际提交预览，并可取消非必要企业字段和业务字段；核心材料要求、业务名称、涉及人员、信息种类和处理目的始终保留；
- 单位名称、联系人、联系方式，以及自由文本中识别出的邮箱、手机、固定电话、姓名和身份证件号码在发送前替换为占位符；AI返回后仅在本机恢复真实值，再保存为可编辑交付草稿；
- 材料版本记录负责人确认预览的时间、自动脱敏数量和排除字段，便于后续说明本次向AI提供了哪些信息；
- AI输出正文、待确认事项和生成摘要，系统拒绝截断或过短结果；服务异常时自动使用确定性基础模板并记录降级原因。

## 材料范围

| 材料族 | 主要内容 | 建立方式 |
| --- | --- | --- |
| 对外规则、告知与同意 | 各类人群告知、未成年人规则、敏感信息同意、出境告知、安全事件通知 | 基础或条件触发 |
| 内部制度与指引 | 内部管理要求、个人请求处理指引、安全事件应急要求 | 基础材料 |
| 协议与权责约定 | 委托处理协议、共同处理权责约定 | 条件触发 |
| 台账与处理记录 | 处理活动、外部接收方、权利请求、同意撤回和安全事件记录 | 持续维护或事件留痕 |
| 合规审计自查 | 官方检查表、整改、负责人签署和归档 | 专门模块 |
| 个人信息保护影响评估 | 触发判断、风险分析、措施充分性、负责人签署和归档 | 专门模块 |

## 关键安全规则

1. 一份材料最多只能有一个当前有效版本；
2. 版本只能在所属材料内流转和发布；
3. 草稿不能自动完成“已建立正式告知”类任务；
4. 已发布版本不可修改；
5. 业务变化不会自动修改或自动废止正式材料，只产生可追溯的复核提醒；
6. 草稿可由负责人直接发布，不强制增加复核和批准流程；
7. 发布新版本后，旧版本保留为已替代状态，相关变化提醒进入已解决状态。
8. 对外材料只能关联与其面向人群一致的业务，页面和服务端执行双重校验；
9. 员工材料与候选人材料始终分开，不能通过手工请求绕过。

## 后续范围

本版本暂未实现复杂多人权限、电子签名、原始 DOCX/PDF 上传解析和对外公开门户。材料适用性、触发条件、版本状态和发布流程均由确定性规则管理，不依赖 AI。后续可将 AI 用于基于已确认事实润色草稿、解释版本差异、定位受影响段落和生成局部修订建议，但不得自动补造事实、判断“无需建立”或自动发布。
