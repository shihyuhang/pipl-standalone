# 敏感个人信息识别口径 v1.0

## 一、效力与适用顺序

1. 以《中华人民共和国个人信息保护法》第二十八条为首要判断依据：个人信息一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害，才进入敏感个人信息范围。
2. 法律明确列举的生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹，以及不满十四周岁未成年人的个人信息，应依照法律处理。
3. GB/T 45574—2025《数据安全技术 敏感个人信息处理安全要求》用于细化分类、示例、识别边界和安全要求，不得用于扩大或者缩小法律规定的范围。法律法规另有规定时，从其规定。

## 二、平台受控分类

平台只接受以下类别：生物识别信息、宗教信仰信息、特定身份信息、医疗健康信息、金融账户信息、行踪轨迹或精准定位、其他敏感个人信息。

不满十四周岁未成年人的全部个人信息由独立问题确认；一旦选择“涉及”，系统自动按敏感个人信息处理。

## 三、关键边界

- 普通照片或视频不当然属于生物识别信息；经技术处理并用于识别身份时，才归入生物识别信息。
- 普通单位、部门、岗位或职务信息不当然属于特定身份信息。
- 与疾病、医疗就诊无关的身高、体重、血型、血压等基本体质信息，不当然属于医疗健康信息。
- 普通订单、一般交易记录不因包含金额就自动成为金融账户信息。
- 由网络地址推算的粗略位置不是精准定位；连续、带时间的精准定位可能形成行踪轨迹。
- 居民身份证照片属于标准列举的其他敏感个人信息；普通身份证号码等其他字段仍须结合《个人信息保护法》第二十八条的危害标准判断，不能仅按字段名称机械认定。
- 普通个人信息聚合后，如泄露或非法使用容易产生法定危害，也应结合具体场景重新判断。

## 四、产品规则

- 用户不能自由创建敏感类别，只能从受控类别中选择。
- 仅选择“涉及敏感个人信息”而未确认类别时，业务事实不算完整，不能进入快速分流。
- 材料、影响评估推荐、AI 输入与页面展示统一使用类别名称，不以用户自由文本替代分类结论。
- “其他敏感个人信息”不是兜底勾选项；必须依据法定危害标准，由负责人结合具体字段、处理目的和场景确认。
- 敏感个人信息的识别结论应触发特定目的、充分必要、严格保护、影响告知、适用的单独同意和个人信息保护影响评估复核。

## 五、依据

- 《中华人民共和国个人信息保护法》第二十八条至第三十一条、第五十五条至第五十六条。
- GB/T 45574—2025《数据安全技术 敏感个人信息处理安全要求》第4章、第5章及附录A。
