# 任务

根据本次企业建档材料和已有事实，完成下列任务之一：

- `extract_facts`：从用户回答或企业材料中提取候选事实；
- `propose_questions`：识别完成小型处理者建档仍缺少的关键事实，并生成下一批问题。

# 处理要求

1. 优先复用问题树中已注册问题；只有注册问题无法表达必要追问时才生成 `ai_follow_up`。
2. 问题顺序优先考虑会改变路径的事项：处理人数、处理角色、敏感信息、未成年人、对外提供、跨境、自动化决策和公开。
3. 一轮最多提出 8 个问题，最多 3 个 blocking 问题。
4. 已存在 confirmed 事实时，不重复提问；存在矛盾时提出针对冲突的确认问题。
5. 对 B2B 企业至少检查员工、候选人、客户联系人、供应商联系人和网站咨询人，不能因为不面向消费者而判断没有个人信息。
6. 对外资企业单独确认全球 HR、CRM、邮箱、工单、云服务的存储地和境外访问，不从所有权推断跨境。

# 输出

使用 `ai-fact-question-output.v1.schema.json`。每个候选事实必须有来源引用；每个问题必须说明为什么会影响本次评估。
